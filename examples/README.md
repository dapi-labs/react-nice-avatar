# Examples

Examples for react-nice-avatar using Vite.

- [Basic](./basic/) - Basic usage with custom config
- [Random](./random/) - Generating random avatars with a seed
- [Expressions](./expressions/) - Facial expressions (happy, sad, excited, angry, etc.)

## Running an example

```bash
cd examples/<example-name>
npm install
npm run dev
```

Then open http://localhost:5173
